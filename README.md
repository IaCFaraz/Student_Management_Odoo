```bash
git remote add origin https://github.com/YOUR_USERNAME/student-management-odoo.git
```

> Replace `YOUR_USERNAME` with your actual GitHub username.

Example:

```bash
git remote add origin https://github.com/farazbashir/student-management-odoo.git
```

